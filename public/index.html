拋印

照片、PDF、Word、貼上的文字、甚至一個網址,通通拋過去,直接從家裡的印表機印出來。手機也能用,不用另外裝驅動程式。

開始使用 看看能做什麼
1

選擇檔案

上傳照片 / PDF / Word / PPT / Excel,或直接貼上文字、貼網址、掃描文件

2

設定列印選項

選頁碼、彩色或黑白、單雙面、版面,想加浮水印、頁碼也可以

3

送出,自動列印

送出後直接呼叫家裡的印表機,不用再傳檔案來傳檔案去

拋印能做什麼

多種格式都能印

照片(自動轉正、裁邊)、PDF、Word / PPT / Excel、純文字 / Markdown,一次選多個檔案還能合併成一份

貼上文字 / 網頁轉 PDF

不用先存成檔案,直接貼文字或貼網址就能轉成 PDF 列印

掃描文件

電腦有接掃描器或多功能事務機的話,可以直接掃描後送印

頁面縮圖選頁

上傳後可以看每一頁縮圖,點選要印哪幾頁、拖曳調整順序

版面模式

2 合 1 / 4 合 1 省紙、小冊子自動拼版、海報拼貼放大列印

浮水印 / 頁首頁尾 / 頁碼

進階列印選項可以加上浮水印文字、頁首頁尾文字、自動頁碼

密碼保護

帳號密碼登入,登入失敗次數過多會自動鎖定一段時間

多主題 / 多語言

深色 / 淺色 / 護眼三種主題,中文 / English / 日本語三種介面語言

手機也能用

介面是響應式設計,手機瀏覽器打開就能上傳、選頁、送印

常見問題

印表機需要跟這個網站在同一台電腦上嗎?

是的。拋印必須跑在實際接著印表機(或掃描器)的那台電腦上,才能直接呼叫印表機驅動程式。

掃描功能一定要有掃描器嗎?

對,需要這台電腦實際接有掃描器或多功能事務機,透過 Windows 內建的 WIA 存取。沒有的話這個分頁會提示找不到掃描器。

雙面列印一定會成功嗎?

要看印表機本身有沒有自動雙面列印的硬體機構。噴墨事務機大多數沒有,即使選了雙面,實際出紙也可能還是單面,請以實際印出的紙張為準。
